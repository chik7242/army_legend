# ARMY LEGEND v2

Новая сборка Telegram-магазина в чёрно-золотом стиле.

## Состав
- `bot.py` — aiogram 3, FastAPI, проверка Telegram Mini App initData, Telegram Stars, SQLite и автоматическая выдача цифровых ключей.
- `static/` — Mini App и административная панель.
- `render.yaml` — пример настройки Render с постоянным диском.
- `.env.example` — перечень переменных окружения.

## Настройка Render
Рекомендуется развернуть как Web Service с persistent disk, смонтированным в `/var/data`.
Команды:
- Build: `pip install -r requirements.txt`
- Start: `python bot.py`
- `DB_PATH=/var/data/store.db`
- `APP_URL` — точный HTTPS URL сервиса
- Добавить `BOT_TOKEN`, `BOT_USERNAME`, `SUPPORT_USERNAME`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`.

Важно: Render Free не предоставляет постоянный диск для SQLite. Для реального магазина нужен тариф/конфигурация с persistent disk, иначе база заказов и ключей может потеряться при перезапуске или redeploy.

## Первый запуск
1. Установите переменные окружения в Render. Не загружайте `.env` и не публикуйте токен/пароли.
2. В BotFather настройте Menu Button URL на значение `APP_URL` (бот также выдаёт Web App кнопку в `/start`).
3. После запуска проверьте `/health`.
4. Откройте `/admin`, войдите с `ADMIN_USERNAME` и `ADMIN_PASSWORD`.
5. Создайте товары, затем добавьте ключи на склад (по одному ключу в строке).
6. Проведите тестовую покупку на минимальную сумму.

## Оплата и ограничения
Цифровые товары в Telegram оплачиваются через Telegram Stars (`XTR`). Успешная оплата обрабатывается update `successful_payment`; ключ выдаётся в чате с ботом. Если товар закончился между оформлением и оплатой, заказ помечается `paid_waiting_stock`, автоматической повторной выдачи из панели пока нет — такую ситуацию нужно обработать вручную. Автоматические возвраты и повторная доставка после сбоя не реализованы. Это стартовая рабочая сборка, не прошедшая независимый аудит безопасности и нагрузочное тестирование.
